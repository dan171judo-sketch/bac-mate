În matematică, mulțimile sunt seturi de elemente distincte. Pentru a înțelege cum se pot combina, trebuie să ne gândim la ele ca la colecții de obiecte. De exemplu, dacă avem două colecții de fructe, una cu mere și una cu pere, putem studia cum se pot uni, intersecta sau diferenția aceste colecții. Aceste operații sunt esențiale pentru a rezolva probleme complexe, inclusiv cele de tip Bac. În această lecție, vom explora cele trei operații principale: reuniunea, intersecția și diferența.

Reuniunea a două mulțimi este operația care combină toate elementele din ambele mulțimi, fără a le repeta. De exemplu, dacă avem mulțimile A = {1, 2, 3} și B = {2, 3, 4}, reuniunea lor este {1, 2, 3, 4}. Acest proces implică scrierea tuturor elementelor din ambele mulțimi și eliminarea duplicatelor. Este important să reținem că într-o mulțime, fiecare element este unic, deci nu putem avea două copii ale aceluiași element. Acest lucru este esențial pentru a evita greșeli în rezolvarea problemelor de tip Bac.

Intersecția a două mulțimi este mulțimea elementelor care aparțin amânduror mulțimilor. În cazul mulțimilor A = {1, 2, 3} și B = {2, 3, 4}, intersecția lor este {2, 3}. Acest concept este important pentru a identifica elementele comune între mulțimi, ceea ce este frecvent în problemele de logică. Este esențial să reținem că intersecția nu include elemente care aparțin doar unei singure mulțimi, ci doar cele care sunt comune.

Diferența a două mulțimi este mulțimea elementelor care aparțin primei mulțimi, dar nu aparțin celei de a doua. În cazul mulțimilor A = {1, 2, 3} și B = {2, 3, 4}, diferența A \ B este {1}. Acest concept este util pentru a elimina elemente inutile dintr-o mulțime, ceea ce este frecvent în problemele de tip Bac. Este important să reținem că diferența nu include elemente din a doua mulțime, ci doar cele din prima care nu sunt prezentă în a doua.
